# 验收矩阵与冻结问题集

版本V0.1，2026-10-27。对应PRD V1.3；T01～T10指实施计划任务。当前为验收设计，所有运行检查均未执行。

## 1. 证据分层与通过条件

- L：本地真实解析器、SQLite及业务接口测试；模型/OCR由可控适配器替代。只证明本地业务规则。
- R：真实DeepSeek或腾讯云OCR调用，记录目标、模拟载荷版本、请求ID、用量及结果。不能用L替代R。
- B：桌面/手机浏览器操作、原型对照、截图和实际页面检查。
- S：目标Ubuntu服务器上的重启、HTTPS、共用资源和旧项目回归。
- H：使用者按原型和验收路径人工确认；开发者自测不自动视为H。

每份报告记录版本/提交、语料manifest哈希、环境、时间、预期、实际、证据路径、通过/失败/未测试/阻塞。未执行不能填写通过。

40道正常题至少36道正确，其中Q01～Q24精确字段题必须全部正确；对应来源不符或添加无依据事实均判失败。8道无答案题、6道歧义/冲突题及更新删除关键回归全部通过，不能由总体分数抵消。对任意资料的识别率不在此固定样本结论内。

## 8. 环境与真实调用检查

- 首轮真实服务建议限制为3个模拟问答、1张文字图和1张规则表格图；在执行前列明目标服务、具体载荷与预计调用量。通过后再按冻结集开展完整R检查。
- DeepSeek记录实际模型标识、API地址来源和用量；腾讯OCR记录接口、RequestId、免费资源包适用情况及后付费配置，不把Key打印进证据。
- 目标服务器检查50份有效文件、累计10,000条Excel记录与3人同时在线时的延迟、峰值资源和旧项目健康，不只运行空数据库。
- 前端检查1440×900、1366×768、1440×720、390×844及375px宽度；现有home、session、states、staff、materials五页HTML原型已交付，源码与ZIP一致性已核对，渲染、交互及B/H检查尚未执行。登录与手机界面沿用现有视觉补齐，不要求额外购买墨刀积分；不能以默认组件或源码包含按钮代替视觉验收。
- HTTPS检查证书受信任、公网访问、自动续期与续期加载；备份恢复在独立目录进行，重启与入口改动须先评估旧项目影响。
