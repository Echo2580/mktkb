# T207-FIX-SCORE 验收证据 07：打分路径零出站 / 不读 .env / 不读 H1-H2（运行时守卫）

## 方法

`probe_zero_call.py` 在进程内把 `socket.socket.connect` 替换为"记录并抛错"，
把 `Path.read_bytes/read_text` 包一层记录 `.env` 与含 `H1`/`H2`/`holdout`/`HO` 的路径，
然后直接调用 `score_run` + `decide_run` 对 R1 产物评分。

## 命令

    set PYTHONPATH=%CD%\backend\src
    .venv\Scripts\python.exe -X utf8 -B evidence\verify\probe_zero_call.py

## 输出

    {"socket_connects": [], "env_reads": [], "h1_h2_reads": [],
     "real_calls_from_manifest": 117, "b0_passed": 38, "b0_exact_passed": 24,
     "release_ready": false, "decision": "blocked",
     "hard_failures": ["trace_integrity"]}

- `socket_connects=[]`：本次打分 0 次 socket 连接（`real_calls=117` 只是从 R1
  `run_manifest/summary` 读出的历史计量，不是本次发出）。
- `env_reads=[]`、`h1_h2_reads=[]`：打分路径未读 `.env` / H1 / H2 / holdout。
- 同一路径得到 b0 38/40、exact 24/24，与 §03 的 CLI 重跑一致。

## 限制

这是对"打分路径"的运行时证明；开发助手此前是否在别处联网，验收无法从产物反推。
本包改动只涉及纯函数打分（新增 `citation_number_keys` 与 opt-in 参数），
`p2_scoring`/`scorers`/`p2_score_run` 的 import 与调用链中无 provider / HTTP 客户端。
