## EXCEL-HEADER-EMPTY-COLUMN

### 一句话

xlsx 解析器的表头启发式用「**本行非空单元格数**」当阈值去要求下一行；当某列**所有数据格为空**
而表头行该列有值时，数据行「占用列数」反而小于表头行非空数，**表头拿不到加分、数据行拿到**，
于是**整条数据行被当成表头**，产物是「字段名 = 业务值」的静默错解析。

### 位置（只读引用，未改动）

| 项 | 值 |
|---|---|
| 文件 | `backend/src/mktkb/ingestion/parsers/excel.py` |
| SHA256（R1 实测，未改） | 见 `evidence-r1/09r1-preservation.json` 的 `frozen_inputs.product_parser_unchanged = true` |
| 触发函数 | `:112-130 _find_header_index` |
| 关键行 | `:121-124`（`for _n, _next_values, _nw, next_occupied, _nm in rows[index + 1 : index + 3]: if next_occupied >= len(nonempty): next_has_same_width = True`） |
| 打分 | `:125 score = (3 if all_strings else 0) + (2 if next_has_same_width else 0) + (1 if len(nonempty) >= 3 else 0)` |
| 平手规则 | `:126 if best is None or score > best[0]` —— 严格大于，故**同分时先者胜**；缺陷正是让数据行**分数更高**而不是同分 |
| 后果放大点 | `:248-283`（表头行被选中后才产出 `header_names` / `fields`） |

### 最小复现（合成数据，不含任何题面/标签/答案值）

**形状**：1 个工作表（表名 `示例表`），1 个表头行 + 2 个数据行，列依次为
`标识` `门店` `物品` `失效日期` `生效日期`；**唯一变量**是 `失效日期` 列在所有数据行是否为空。

| 项 | 值 |
|---|---|
| 工作表名 | `示例表` |
| 列名（逐字） | `标识`, `门店`, `物品`, `失效日期`, `生效日期` |
| 表头行 | 第 1 行 |
| 数据行 | 第 2–3 行（2 行） |
| 合成标识 | `X01`, `X02`（不是任何真实记录码） |
| 合成业务值 | `示例门店甲/乙`、`示例物品一/二`（不是任何真实门店/物品） |
| 是否涉及题面 | **否**。全是占位串；不含 H2 题面、标签、答案、目标值、密文 |
| 变量 | `失效日期` 整列为空 ⇄ 写哨兵 `未声明` |

**实测（`11r1-defect-repro.json`）**：

| 观察项 | A：`失效日期` 整列为空（缺陷形态） | B：`失效日期` 写 `未声明`（绕开形态） |
|---|---|---|
| `report.sheets[0].header_row` | **2**（应为 1） | **1** ✅ |
| 产出 unit 数 | 1 | 2 |
| 首个 unit 的 `fields` 键 | `X01` / `示例门店甲` / `示例物品一` / `2026-01-01` / `列4` —— **全是业务值** | `标识` / `门店` / `物品` / `生效日期` / `失效日期` —— **全是表头** |
| 首个 unit 是否含 `标识` 表头 | **否** | 是 |
| 首个 unit 的 `失效日期` 字段 | 不存在（`None`） | `未声明` |
| `_effective_range(raw_fields)` | **`("none", None, None)`** | **`("range", "2026-01-01", None)`** |

同一行 unit 的 `text`（解析器自报的"这一行是什么"）最能说明"静默"两个字：

```text
A（缺陷）：X01: X02 | 示例门店甲: 示例门店乙 | 示例物品一: 示例物品二 | 2026-01-01: 2026-01-01
B（绕开）：标识: X01 | 门店: 示例门店甲 | 物品: 示例物品一 | 失效日期: 未声明 | 生效日期: 2026-01-01
```

A 里**键是上一行的业务值、值是下一行的业务值**，两行被压成一行；没有任何告警。

打分过程（同一个脚本逐行重算，公式抄自 `:112-130`）：

| 行 | 非空数 | `next_has_same_width` | 得分 | A 是否被选中 |
|---:|---:|---|---:|---|
| 1（真表头） | 5 | `false`（下一行占用 4 < 5） | **4** | 否 |
| 2（首个数据行） | 4 | `true`（下一行占用 4 ≥ 4） | **6** | **是** |
| 3（末尾数据行） | 4 | `false`（后面没有行了） | 4 | 否 |

> 一句话读法：**表头比数据行"更宽"这件事，在启发式里是减分项。** 空列让表头变宽又让数据行变窄，
> 两个方向的偏差叠加，必然翻盘。

### 影响

1. **无 `标识`**：`fields` 里没有 `标识` 键 ⇒ 下游 `retrieval/index.py:analyze_fields` 找不到 id 头
   ⇒ 实体键退化为 `…|doc:<uuid>|unit:<uuid>`（`index.py:126`）⇒ **任何"按记录码对齐"的 target 永远匹配不上**。
2. **无日期**：`生效日期` / `失效日期` 都不是表头 ⇒ `raw_fields` 里没有这两个键
   ⇒ `_effective_range` 返回 `("none", None, None)`（`p2_hard_evidence.py:1501`）
   ⇒ 日期检查**整段失效**：既不断言过期，也不断言未生效。
3. **静默解析错**（最危险的一点）：**不抛异常、不报警告、`report.quality.complete` 仍为 true**。
   解析器"成功"产出了 unit，只是每一行都变成了「字段名=业务值 → 值=下一行的值」的错位记录。
   失败模式是**看起来成功的错**，而不是明显报错——这会让"没有证据"被读成"没有问题"。
4. **对 v3 的具体后果**：`V05`（D01 v4）与 `V06`（D02 v2）整表命中；36 条 target 里 **7 条不可对齐**
   （`P08@D01v4`、`P07@D01v4`、`P08@D01v4`、`P07@D01v4`、`S02@D02v2`、`S03@D02v2`、`S02@D02v2`），
   波及 runs 2/3 的 6 道题（C09/C10/C15/C20/C29/C30）。
5. **触发面不限于 v3**：凡「表格类源里有整列为空的数据列」都会被命中（这是数据卫生的常见形态，
   例如"备注""照片 URL""停用原因"）。缺陷是**产品级**的，不是 v3 语料特有的。

### 为什么暂缓修（不是"不重要"，是"顺序问题"）

**2026-11-15 经理裁定**：**先冻结 v3 量具，产品修复单独开包。**

理由（登记人理解，供复核）：

1. 改 `_find_header_index` 会改变**所有 xlsx** 的表头判定口径，影响面覆盖已冻结的 v2 语料判定路径
   与 C 冻结 12 中的 `p2_hard_evidence.py` 消费方式；它属于"改量具"，必须走独立验收（改码 + 回归 + 双人复算）。
2. 本轮的直接阻塞是"v3 语料能不能被判"，而这一点可以**纯数据侧**解决（见下）。
   把量具改动和语料返工混在同一包，会让"评审到底在评什么"失焦。
3. 一旦先改产品，v3 的所有 SHA / 冻结清单都得等产品定稿才能出；先出语料可以并行推进。

因此：**本轮不改 `ingestion/parsers/excel.py`**（`09r1-preservation.json` 的
`frozen_inputs.product_parser_unchanged = true`、`product_parser_unchanged = true` 为证）。
本条目保持 **`OPEN`**，待独立开包修。

### 建议的最小修复方向（**未实施**，交产品包评审）

不改判据、只让候选表头不被"数据行更宽"反超。可行方向（按侵入性从低到高）：

1. **并列/更宽时优先更早行**：`score > best[0]` 改 `>=`（同分取后者→前者）。最小改动，但会改变
   所有现有 xlsx 的平手结果，需要全量回归。
2. **候选表头必须含 `ID_HEADERS` 之一**（`retrieval/index.py:39`）：把"像表头"从"宽度博弈"
   改成"结构断言"，语义最正确，但可能让无 `标识` 的合法表格失去表头。
3. **阈值改用 max(本行非空数, 后续行最大占用数)**：保留现有平手语义，只消除"表头比数据宽即失分"的偏差。

三者都需要独立验收 + 全量 xlsx 回归 + 与 v2 判定的差分对照。**本轮不做。**
