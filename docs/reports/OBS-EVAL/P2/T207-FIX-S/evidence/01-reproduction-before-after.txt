def score(text):
    row = {"case_id": case.case_id, "suite": case.suite, "stratum": case.stratum,
           "conversation_id": "conv-q39", "status": "ok", "error_code": None,
           "planned_turns": 1, "turns_executed": 1,
           "turns": [{"turn": 1, "status": "ok", "error_code": None,
                      "product": {"kind": "answer", "text": text, "trace_id": "trace-q39",
                                  "trace_path": "rag", "sources": [dict(SRC)],
                                  "http_status": 200}}]}
    scored = p2.score_public_case(case, row, document_codes=DOCUMENT_CODES,
                                  allowed_doc_codes={"D10"})
    checks = {c["check_id"]: c["status"] for c in scored.score.checks}
    return scored.score.status, checks

   `2026-10-30 16:00` 永远匹配不上 —— 与答案对错无关。
2) 精确调用链（行号由 inspect 定位，非手写）：
   p2_scoring.score_public_case:878(前)/881(后)  -> scorers.score_case:1033(前)/1083(后)

   只是从不传 opt-in 参数。
