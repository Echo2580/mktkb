## 1. 新旧口径对照矩阵（探针原始输出在 §2/§3）

| P-R1 用例 | 场景 | 旧口径（修复前 service.py） | 新口径（工作树） | 说明 |
|---|---|---|---|---|
| (a) `..._moved_into_value_position_is_accepted` | 问题含 8000，答案"审批门槛为 8000 元…" | **不成立**：带 `question=` → `TypeError: unexpected keyword argument 'question'`；不带 → `REJECT`（来源里没有 8000） | `ACCEPT` | 放行只来自"问题原文 token 进白名单"；同文本不传 question 仍 REJECT（单测内已断言） |
| (b) `..._fabricated_value_in_same_value_position_is_rejected` | 同句式换 1.88（问题/来源都没有） | 捕获不到（`TypeError`），语义为"旧口径也拒" | `REJECT`：回答包含引用来源中不存在的数据值 | 与 (a) 成对，证明放宽只认问题原文逐字 token |
| (c) `..._record_path_without_question_keeps_three_samples_verbatim` | 记录型三样本（不带 question） | `ACCEPT`/`ACCEPT`/`REJECT`，与新版**逐字相同** | 同左 | 旧口径下该用例即**通过**（见 §4 的 2 passed），说明"不变"成立 |
| (d) `..._adversarial_wrong_premise_is_accepted_as_known_widening` | 问题给错值 3000、答案照抄 | **不成立**：同 (a)，`TypeError`；不带 question → `REJECT` | `ACCEPT` | 已知放宽：只按"问题原文逐字出现"背书，不判前提真伪 |
| 既有 #3（顺带复核） | 两行都在 allowed/evidence，只引用 A 行并用 B 行的 2.5 | — | 只引用 A 行 → `REJECT`；两行都引用 → `ACCEPT` | 证明"未引用来源不能背书"方向正确（`_cited_corpus` 只拼实际引用行） |

结论：单测 (a)/(d) 的"接受"断言确实**钉住了本次放宽**（旧口径下不可能通过），(b) 钉住拒绝边界，(c) 钉住记录型不变。
