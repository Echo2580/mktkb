# T207-FIX-H2KIND 独立验收证据 02：P1 默认口径差分（0 分歧）

## 方法（不 stash、不切分支、只读导出）
1. `git archive HEAD backend/src` 导出 107 个文件到工作区外临时目录（HEAD=3bc8347；评分源码与 0260b7b 相同）；
2. 同一 probe（`probe_default_diff.py`）两臂运行：OLD=临时目录 HEAD 源码，NEW=工作区源码；
   probe 自检输出 `module` 与 `has_compat_flag`（OLD=false / NEW=true），确认两臂确实加载不同实现；
3. 输入：fixtures/evaluation/{b0,badcase,regression}.jsonl（load_cases）+ holdout-questions.jsonl（只含题面）
   = **90 条 case**；× 10 种 actual kind（含空串、service_error）× 4 种文本（空/含数字日期/拒答文案/纯空白）
   × 2 种引用（无引用/带 D01 引用）= **7200 次 score_case**（报告为 2160，本次规模 3.3 倍）；
4. 比对：整份结果 JSON（sort_keys；含 checks/metrics/refused/status 等）逐字节 sha256。

## 定点：fixtures 的 refusal 题在默认路径仍 fail（旧行为）
- 90 题中 expected_kind=refusal 共 **2 题**（fixtures 内 H19/H30 形态）；
- 默认路径下 actual=not_found / no_answer：**0 次 pass**；actual=refusal：16 次 pass（2 题×4 文本×2 引用，相等分支）。
→ 放宽只发生在 `score_public_case` 显式打开处，P1 默认口径逐字不变。
