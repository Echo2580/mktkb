## C. 过度收紧的残余风险（已复现，非验收失败项）

1. 区域形态启发式对“2 字店内位置 + 区”误判：`物料区的海报在哪`→澄清“物料区”；`陈列区/收银区/展示区` 同样命中。`促销道具区` 因词边界不命中；`仓库区/展区/城市片区/高度区间/华东大区/B区1号货架` 已排除。155 题真实语料、b0/badcase/regression 均无此措辞 → 风险限定在未收录的店内位置措辞（开发 report §5 已声明）。
2. 新 topic-switch 对“无字段词 follow-up”一律 reset：`那款呢/这款呢/单位呢/保质期是多少/还有呢/再说说` 由 base 的“继承实体并按上一字段作答”变为清空/澄清。字段词表内追问（电话/数量/价格/规格）、指代词（它/这个/该…）、分页、裸补槽、切换词均保持继承。
3. 词表外 `*店` 在 parse/RAG 直答层仍继承上一轮门店（`西单店/长安店/新街口店` → `filters.store=城东店`，base 与当前相同）；产品 HTTP 层由意图层拒答为 `not_found`，未复现 ERR-01 的用户可见串店。开发证据 04 所述“P0 live 预算测试锁定”未在本次只读核对中复现到关联（该测试两问均为已知门店）；列为待 PM 裁量的残余项。
4. `_RAG_OWNED_CLARIFICATION_FILTER="identifier"` 为产品层识别键：已核实 `answer_question` 在检索前 clarification 分支返回，值不写入 `state.identifier`、不持久化；第三轮补门店验证 state 未被污染。
