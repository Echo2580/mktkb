## 运行边界与交付

- 使用 P2 定向集成测试和独立编写的负例，沿用实际版本和隔离目录。浏览器或环境不足时给出 `NOT-RUN` 和原因，交主人决定。确有必要的 T900 真实抽验单独提出，原验收口径为获批的最多 5 题、独立成本中心 2 元，实际受最新预算、请求余量和新 GO 约束。
- 每项返回 `PASS`、`FAIL`、`BLOCKED` 或 `NOT-RUN`，附命令或工件引用、版本、日期、实际输出、限制和复核人。开发自测、独立离线、已有真实运行、浏览器四列分开。结论明确为通过、有保留通过、返工或阻断。必要硬证据未知、硬失败、越权、越预算或批准阈值未满足时维持阻断。
- 交付 `docs/reports/OBS-EVAL/P2/review.md`、`docs/reports/OBS-EVAL/P2/p2-report.md` 所需独立结论与 `docs/reports/OBS-EVAL/P2/evidence/T900/` 证据索引。经理依据独立结论汇总，最终发布由主人决定。
